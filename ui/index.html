    Terrain & Ground
    Contours (minor + major, labelled) are drawn as 2D lines in the site plan on every import. Auto picks 15-25 lines from the relief.
    Buildings

    Where OSM has few buildings (villages), Overture Maps footprints (Google Open Buildings, Microsoft ML, Esri) are added if they overlap no OSM building. Marked "estimated", height from Overture height / floors or the default; Source property names the dataset; group "Buildings (Overture)". Downloaded once per site (a few MB, ~10 s), never blocks the OSM fetch. Also on in the super-light preset.

    Where a LoD2 dataset covers the site (Baden-Württemberg LGL, Netherlands 3DBAG, Japan PLATEAU, Switzerland swissBUILDINGS3D), measured buildings with real roof planes replace the OSM / Overture ones they overlap (by at least half of the smaller footprint; OSM id and name/address tags are kept, unmatched OSM buildings stay). Heights are relative to the terrain under each footprint. Roofs become Roof elements (off = flat blocks, as in the super-light preset); very large sites are capped at 400 Roof/Morph elements, the rest become blocks. Downloaded once per site, never blocks the OSM fetch; Japan and Switzerland only with the large-download option. Source property names the dataset; credit shown in the report.

    Trees & shrubs

    Estimated from mapped areas, not individual surveyed trees. Density per area type: mangrove 1 per 25 m² (6 m), orchard rows 1 per 30 m² (5 m), nursery 1 per 15 m² (3 m), parks & gardens 1 per 120 m² (10 m, kept off buildings/water/roads/pitches), woods 1 per 40 m². Woods are off by default (can be thousands of objects). Fixed seed, one Archicad group per area, sized like other trees (measured nDOM where available).

    Hedges (barrier=hedge) become one Hedge Model per segment; shrubs (natural=shrub, plus scatter in shrubbery/scrub areas) use the Shrubs part (2D symbol in 2D mode). Groups: Shrubs and Hedges next to Trees.

    Falls back to Light 3D (warning in the build report) when the part is not loaded in Archicad. Conifers (leaf_type needleleaved) get the pine part when the data carries that tag.

    Size per tree: OSM tag, else measured (nDOM, where available), else typical genus/species size, else the broadleaf/conifer defaults, else the fallback height. Table values are typical, not measured.

    More features

    Rail, light rail, tram, subway, narrow gauge ways (not disused/abandoned) become one Beam per segment like roads (3 m per track, gauge/tracks tags used); platforms become thin Slabs. Groups: Railways.

    barrier=wall / retaining_wall / city_wall use the Wall tool (<=5 m pieces, base on the terrain; heights 2 / 1.5 / 4 m unless tagged). Fences and guard rails use the Railing tool (1.5 / 0.8 m). Group: Walls & fences.

    building:part with height / min_height / levels becomes one Slab per part (the parent outline only where no part covers it); roof:shape gabled / hipped / pyramidal / skillion with roof:height becomes a Roof element, anything unclear keeps the flat block. Parts sit in a Building subgroup inside Buildings.

    Parking, pitches, playgrounds, pedestrian areas, squares: 0.05 m Slab on flat ground, draped Mesh on a slope. Group: Ground surfaces.

    man_made=pier / bridge areas become a Slab at the deck height (pier: water level + 1 m; bridge: highest bridge road inside). Group: Piers.

    Off by default. power=tower / pole become Columns; power lines are only counted. Group: Power.
